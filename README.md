Token Launch Radar (model radar-2): pre-token protocols from a sealed DefiLlama snapshot, ranked by an implied value computed from TVL, seven-day growth, age with no token, chain count and a product penalty — with a concrete farm plan for each protocol. Built by an AI agent for make.fun's "Build the best token launch radar" bounty, $1,325 in USDC.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../input/snapshot.json
```

Node 22 or later, standard library only, no network. The program reads the sealed snapshot, writes the ranked board to `out/board.json`, the dashboard data to `out/data.js`, copies `dashboard/` and `screenshots/` to `out/`, and writes `out/dossier.json`. Run it twice into two directories and the outputs are byte-identical.
